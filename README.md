## 픽션AI는

픽션AI는 긴 프롬프트 없이 **추천을 고르고, 이어 쓰고, 배포하는** 웹소설 창작 플랫폼입니다.
창작·유통·정산이 하나의 앱 안에서 끊기지 않고 이어집니다.

플랫폼은 늘었지만 이야기를 처음부터 끝까지 완주하는 사람은 늘지 않았습니다.
예비 작가를 멈추게 하는 것은 재능이 아니라 진입 단계의 네 가지 관문 — **백지 공포, 연재 압박, 집필 비용, 불투명한 정산** — 입니다.
픽션AI는 이 네 관문을 제품 구조로 걷어냅니다.

## 기술 구조 — 300화를 견디는 엔진

웹소설은 회차가 쌓인 뒤부터가 본편입니다. 범용 AI는 5화 무렵, 소설 특화 툴은 30화 무렵에 인물과 복선을 잃습니다.
픽션AI는 300화 규격을 목표로 엔진을 4개 층으로 설계했습니다.

```
 ┌────────────────────────────────────────────────────────────┐
 │ ④ 검증 루프   회차 생성마다 설정 항목 자동 대조 → 충돌 시 재생성 │
 ├────────────────────────────────────────────────────────────┤
 │ ③ 기질 주입   PICK한 카드의 기질·성격·내력을 생성 단계에 주입     │
 ├────────────────────────────────────────────────────────────┤
 │ ② RAG 장기 기억  인물·관계·사건·복선 추출 → 외부 저장소 → 필요분 호출 │
 ├────────────────────────────────────────────────────────────┤
 │ ① 웹소설 특화 sLLM  오픈 웨이트 모델 파인튜닝 · 자체 서빙         │
 └────────────────────────────────────────────────────────────┘
```

| 규격 | 상태 |
|---|---|
| 30화 · 단편 | ✅ 제공 중 — 완결 프리셋과 이어쓰기 |
| 100화 · 장편 검증 | 🔄 검증 중 — 1~100화 연속 생성 자동화 테스트 |
| 300화 · 장편 규격 | 🧪 학습 중 — sLLM 추가 학습, RAG 저장소 확장 |

목표 지표: 300화 기준 설정 검증 항목 통과율 **98.5%** (목표치이며, 측정값으로 공개할 예정입니다)

## 창작자 정산과 수익 모델

작품 개설과 회차 집필 원가는 **플랫폼이 전액 부담**합니다. 작가는 비용 없이 시작하고, 첫 독자부터 정산받습니다.

```
총결제액 − 스토어/PG 수수료 = 순매출
순매출 − 플랫폼 운영수수료 10% = 정산기준액
정산기준액 → 작가 50 : 플랫폼 50   (순매출 기준 작가 45%)
```

수익 레이어는 **광고 · 픽코인 · 정액제 · 후원(작가 90%)** 네 가지이며, 모두 같은 정산 원장에서 회차 단위로 산정되어 작가 원장에 적립됩니다.
